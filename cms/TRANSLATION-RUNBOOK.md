# Инструкция: продолжить перевод контента на английский

Этот файл — рабочая памятка для сессии, которая продолжает начатый перевод.
Читать целиком перед началом.

## Что уже сделано

- В схеме Sanity есть поля `titleEn`, `excerptEn`, `bodyHtmlEn`, `specializationEn`.
- Сайт на английской версии берёт поле `…En`, если оно заполнено, иначе русское.
- Переводы складываются партиями в `cms/i18n-batches/batch-NNN.json`.
- Общий файл собирается командой `node cms/i18n-merge.mjs`.

## Порядок работы

**1. Узнать, что уже переведено.**

```
node cms/i18n-merge.mjs
```

Печатает число партий, документов по типам и знаков. Дальше получить список
уже переведённых `_id`:

```
node -e "console.log(require('./cms/i18n-translated.json').map(x=>x._id).join('\n'))"
```

**2. Взять следующую порцию из CMS.**

Данные читаются через браузер (в песочнице сеть до Sanity закрыта). Открыть
вкладку на `https://ogu6ewxe.apicdn.sanity.io` и выполнить запрос:

```js
const B='https://ogu6ewxe.apicdn.sanity.io/v2023-05-03/data/query/production?query=';
const q=async s=>(await (await fetch(B+encodeURIComponent(s))).json()).result;
const r=await q('*[_type=="doctor" && defined(slug.current)]|order(_id asc)[N...M]{_id,"slug":slug.current,name,bodyHtml}');
JSON.stringify(r);
```

Порядок: сначала оставшиеся `doctor`, затем `disease`. Для заболеваний нужны
поля `_id`, `slug`, `title`, `bodyHtml` — переводить `title` и `bodyHtml`.

Размер порции: 6 врачей или 4 заболевания за раз. Больше не брать — ответ
не поместится.

**3. Перевести и записать новую партию.**

Новый файл `cms/i18n-batches/batch-NNN.json` со следующим номером. Формат:

```json
[
  {
    "_id": "doctor-ivan-ivanov",
    "_type": "doctor",
    "slug": "ivan-ivanov",
    "fields": { "bodyHtml": "<p>...</p>" }
  }
]
```

Для заболеваний в `fields` идут `title` и `bodyHtml`.

**4. Пересобрать и проверить.**

```
node cms/i18n-merge.mjs
```

## Правила перевода

- Переводить по смыслу, а не пословно. Это медицинский сайт: регистр деловой,
  без рекламных восклицаний, термины — общепринятые английские.
- **Разметку сохранять полностью**: абзацы, списки, заголовки, `<strong>`,
  ссылки, картинки, атрибуты `class`. Структура должна совпадать с русской.
- Названия израильских клиник и университетов давать в принятом английском
  написании (Ichilov, Sheba, Hadassah, Assuta, Soroka, Technion, Tel Aviv
  University, Sourasky, Rabin Medical Centre и так далее).
- Имена врачей — в общепринятой латинской транскрипции, а не транслитом
  с русского. Если имя встречается в англоязычных публикациях, брать оттуда.
- Международные ассоциации называть их настоящими английскими именами
  (ASCO, ESMO, EHA, AANS, ISAKOS и подобные), а не переводить обратно дословно.
- Абсолютные ссылки на `assuta.org` заменять на относительные (`/bolezni/...`).
- Служебный мусор из исходника (редакторские заметки, шаблонные куски про
  авторские права) в перевод не переносить, а отметить в отчёте.
- Битую разметку исходника (лишние `</p>` в начале, вложенные `<p>`)
  в английской версии исправлять.

## Чего не делать

- Не писать в Sanity. Заливкой занимается Давид скриптом `cms/i18n-import.mjs`.
- Не трогать русские поля.
- Не переписывать уже готовые партии.
- Не коммитить и не пушить — это тоже делает Давид.

## В конце сессии

Коротко отчитаться: сколько партий добавлено, сколько документов и знаков
готово суммарно, что осталось, и какие дефекты найдены в русских исходниках.
