# Assuta — превью нового сайта (Next.js)

Современная пересборка сайта клиники Ассута на Next.js 14 (App Router) + Tailwind CSS.
Демо-версия для показа клиенту: сохранён фирменный стиль (тёмно-синий #283890 + зелёный #86be56,
шрифт Montserrat), добавлены плавные анимации, адаптив и чистая современная вёрстка.

## Что внутри
- Главная, Врачи (+ карточка врача), Заболевания (+ страница заболевания),
  Направления, Диагностика, Цены, Отзывы, Новости, Контакты.
- Форма заявки (в демо не отправляется на сервер; на боевом сайте — на почту/Telegram/CRM).
- Контент — реальные данные, собранные с assuta.org (для показа).

## Как запустить локально
```bash
npm install
npm run dev
# открыть http://localhost:3000
```

## Как выложить превью (ссылка для клиента)
1. Создать новый репозиторий на GitHub и загрузить в него содержимое этой папки
   (папки node_modules / .next загружать НЕ нужно — они в .gitignore).
2. На vercel.com → Add New → Project → выбрать этот репозиторий → Deploy.
3. Vercel сам всё соберёт и выдаст публичную ссылку вида project.vercel.app.

Технологии: Next.js 14, React 18, Tailwind CSS 3. Без внешних зависимостей для анимации
(IntersectionObserver + CSS) — быстрая и лёгкая сборка.
